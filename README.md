# Namibia–UK Biofertiliser Knowledge Exchange

Website for the Namibia–UK Biofertiliser Knowledge Exchange.

## Preview locally

Ruby 3.2 or later is recommended.

```bash
bundle install
bundle exec jekyll serve --livereload
```

Open [http://127.0.0.1:4000/](http://127.0.0.1:4000/) in your browser.

## Deploy

The site is published with GitHub Pages from the `main` branch.

1. Go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.

Push changes to `main` to rebuild the site automatically.

Live site: [https://namibia-microbiome.github.io/](https://namibia-microbiome.github.io/)
